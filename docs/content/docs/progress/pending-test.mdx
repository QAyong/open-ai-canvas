# 待测试

## AI 提示词优化器

当前代码和生产构建已完成，但以下场景仍需要在真实配置和不同窗口尺寸下由用户确认：

- [x] `web` 前端 TypeScript 检查与生产构建通过。
- [x] 优化面板打开、关闭不再等待 Popover 入场或退出动效。
- [ ] 在 `/create` 中分别测试图片和视频模式的打开、发送、取消、失败重试和关闭。
- [ ] 在图片、视频画布节点中测试优化入口、结果采用和原提示词回填。
- [ ] 逐项测试五种优化方式，确认模式切换不会丢失当前输入。
- [ ] 测试优化模型切换，并确认目标生成模型与优化模型显示和请求职责分离。
- [ ] 测试已连接图片、文本参考，以及“结合参考”没有参考内容时的提示和禁用状态。
- [ ] 测试长提示词、长优化结果、滚动、拖动和四边缩放；确认窗口接近边缘时不会跑出视口。
- [ ] 测试浅色/深色主题和窄窗口布局，确认按钮、输入框和结果文本仍可读且可操作。
- [ ] 使用自定义文本渠道实际发送一次，确认渠道、模型和权限配置正确时不会误报“必须指定系统渠道和模型”。

用户确认上述场景后，再将对应条目移动到功能文档的已验证范围。

## 画布节点自动整理

自动整理入口和布局提交逻辑已完成，以下场景仍需要在实际画布中手工确认：

- [x] `web` 前端 TypeScript 检查与生产构建通过。
- [x] 画布底部视图控制中显示“自动整理节点”按钮。
- [ ] 无选中节点时，确认多个顶层节点会按连线流程布局；无连线时会按网格布局。
- [ ] 选中节点时，确认只移动选中的可移动节点，未选中节点保持原位。
- [ ] 确认锁定节点、容器节点和折叠批次隐藏子节点不会被移动。
- [ ] 点击“撤销”确认可以恢复整理前的位置，并确认刷新画布后布局仍能保存。
- [ ] 在浅色/深色主题、窄窗口和节点数量较多的画布中确认底部按钮可见、可操作且不遮挡主要内容。
