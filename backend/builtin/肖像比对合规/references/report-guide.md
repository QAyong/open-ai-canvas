# compliance_submit_report 示例

下面是一份写实照片、待核验图有一张脸、与一张授权底图比对后给出疑似的报告。数字不用填，服务端会按引擎证据生成。

```json
{
  "style": "realistic",
  "summary": "待核验图为写实剧照，检出 1 张人脸，与授权底图比对的引擎相似度处于疑似区间。五官布局有相近之处，但侧脸角度和光线限制了判断，建议人工复核后再使用。",
  "faces": [
    {
      "index": 1,
      "basis": [
        "脸型与下颌线与底图接近",
        "眉眼距离和眼型有相近之处，鼻梁与嘴型差异不明显"
      ],
      "limitations": [
        "待核验图为约 30 度侧脸，鼻口比对的可靠性下降",
        "授权底图只有 1 张，且光线偏暗"
      ]
    }
  ],
  "suggestions": [
    "补充一张授权人的清晰正脸底图后重新核验",
    "该素材用于公开投放，建议由合规同事人工复核后再使用"
  ]
}
```

没有检出人脸时 `faces` 传空数组，并在 `summary` 里说明素材里没有可比对的人脸；服务端会自动转人工。
